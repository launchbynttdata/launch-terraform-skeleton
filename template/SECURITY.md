# Security Policy

This repository contains a Launch Terraform module and its supporting code. Please report security issues that could affect users of the module, its examples, tests, or repository automation. Reports should describe the affected versions or revisions, the security impact, and steps to reproduce when safe to share. Explain whether the issue could cause unintended access, expose sensitive data, or weaken security controls.

## Reporting a vulnerability

For a **public** repository, use **Security → Advisories → Report a vulnerability** on GitHub. Do not report vulnerabilities in public issues, pull requests, or discussions.

For an **internal or private** repository, contact the repository maintainers through the existing private maintainer channels. Do not post sensitive details in public channels.

Please report issues based on their potential security impact and include enough detail for maintainers to assess and reproduce them. Avoid including real credentials, personal data, or other sensitive production data in a report; use redacted or synthetic examples where possible.

## Scope

Reports may cover exploitable weaknesses in the module's Terraform configuration, shipped examples, tests, dependencies, or repository automation. General usage questions and issues without a security impact should use the repository's normal contribution channels.

Maintainers will assess reports and determine appropriate next steps. This policy does not promise a response or resolution time.
